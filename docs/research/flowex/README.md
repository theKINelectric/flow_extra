# Research records — naming note

These records were written against the code when it was named **Flowex**
(namespace `Flowex.*`, application `:flowex`), through commit `4343066`.
Module names, file paths, and commands quoted in them are historical
observations of that code and are intentionally **not** rewritten — they
are the evidence for the work reviewed at the time.

The maintained project is now **FlowExtra** (`FlowExtra.*`, package and
application `flowextra` / `:flowextra`). The behavior these records
establish is preserved by the renamed suite, which carries every
regression they introduced; see the repository root's `MIGRATION.md` for
the identity mapping and the agreed behavioral differences. Post-rename
receipts should be recorded as new files here rather than edits to the
existing ones.
